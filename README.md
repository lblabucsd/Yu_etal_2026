# Yu_etal_2026
A repository with all relevant code for Yu et al. (2026) from the Lovett-Barron lab.
Colab notebooks with prefix "data_" were used to process behavior or imaging data. Colab notebooks with prefix "Fig." or "EDF." were used to create each subpanel in all main and supplementary figures.
